# DevEcoIDE

钱佳丽的鸿蒙电脑 IDE 体验与布局研究仓库。

## 研究材料

1. [鸿蒙电脑布局与分辨率研究](analysis/harmony-desktop-layouts/index.html)
2. [IDE 字号与组件尺度研究](analysis/ide-typography-components/index.html)
3. [IDE 文件树体验研究](analysis/ide-tree-lab/index.html)

每份材料保留展示页面、研究正文、数据、设计参数、验证记录及页面资源。根目录 `index.html` 是统一入口。

## 目录

```text
analysis/
├── harmony-desktop-layouts/

```

仓库包含 `.nojekyll`，启用 GitHub Pages 时请选择 `main / (root)`。
