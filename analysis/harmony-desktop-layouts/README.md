# 鸿蒙电脑原生应用布局研究

钱佳丽 · 2026-10-20 · v1.3

面向鸿蒙电脑原生软件，整理设备分辨率、逻辑画板、顶部导航、左右导航、两列、三列、IDE 工作台、画布、卡片看板和设置页面。内容列结构与应用顶部区是两个独立维度，不默认给每种布局增加顶部栏。默认设计画板为 1440×960 px；网页支持拖动整体窗口和左、中、右面板，并按断点模拟折叠与恢复。

设计文件中的 px 作为逻辑设计单位：布局、间距和圆角按 1px=1vp 交付，文字按 1px=1fp 交付。市场产品示意是依据官方文档做的结构归纳，不是竞品截图或像素测量。

网页复用相邻研究目录中已核对的 IJ 按钮、输入、表格和导航代码实现；研究布局示意是基于这些基础组件组合的扩展，不属于 Int UI Kit 原始组件。
