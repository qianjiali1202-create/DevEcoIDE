# 验证记录

日期：2026-10-20。环境：本机 Chrome / Playwright。

- 页面展示4种鸿蒙电脑设备/姿态的分辨率分析、8类布局模式、6个市场产品结构对照和12项来源。
- 默认三列布局为1440×960，应用顶部区关闭，目录240、辅助列320，计算出的主内容宽为880、主体高为960。
- 紧凑预设1236×824时自动折叠右侧辅助区，主内容宽996；手动展开右侧并增至420后能提示主内容低于640。
- 应用顶部区可独立开启或关闭：开启后默认48，关闭后高度为0；切换布局会采用对应模式的建议状态。
- 切换“顶部导航+内容”会开启顶部区并将左右列设为0；“恢复推荐”回到无顶部区的三列1440×960。
- 自定义窗口宽高、顶部区、目录列、辅助列和底部区均可即时更新预览与判断。
- 预览中的左、右、底部分隔线及窗口右下角均可拖动；左、右面板拖动受主内容最小640约束。
- “按断点自动折叠”开启时，右侧在1280以下折叠、左侧在960以下折叠，并在窗口恢复后使用之前宽度。
- 分辨率表中的物理像素、屏幕尺寸和比例与华为官方页面一致；PPI及2×逻辑尺寸明确标记为研究换算。
- 390×844视口下，九个章节均未出现整页横向溢出；宽表使用局部滚动。
- 启动页“分析与研究”出现新研究卡片；作者字段为钱佳丽。
- 页面未捕获JavaScript异常或HTTP资源错误；脚本语法和git diff空白检查通过。
